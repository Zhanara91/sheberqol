# Шеберқол

Демо-версия маркетплейса handmade-товаров для Казахстана (прототип в стиле Etsy).

## Как запустить на GitHub Pages

1. Создай новый **публичный** репозиторий (например, `sheberqol`).
2. Загрузи файл `index.html` в корень репозитория.
3. Зайди в **Settings → Pages**.
4. Выбери ветку `main` и папку `/ (root)`.
5. Сохрани.

Через 1–2 минуты сайт будет доступен по адресу:

```
https://ТВОЙ-НИК.github.io/sheberqol/
```

Эту ссылку можно отправлять друзьям — сайт откроется сразу в браузере.

## Особенности

- Полностью на русском языке
- Адаптивный дизайн (хорошо работает на телефоне)
- Поиск, фильтры по категориям, корзина
- Картинки загружаются из внешних источников (нужен интернет)

Это статическая демо-версия. Для полноценного маркетплейса потребуется backend.
